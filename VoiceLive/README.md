# VoiceLive (Android / Kotlin + Jetpack Compose)

এটি Pota-ধরনের লাইভ ভয়েস-চ্যাট অ্যাপের ক্লায়েন্ট। **Phase 1 / Step 1**: Splash + Login screen.

## কীভাবে চালাবেন (নতুনদের জন্য)
1. **Android Studio** ইনস্টল করুন: https://developer.android.com/studio
2. Android Studio খুলে **Open** → এই `VoiceLive` ফোল্ডারটি সিলেক্ট করুন।
3. অপেক্ষা করুন — Android Studio নিজেই Gradle ও দরকারি জিনিস ডাউনলোড করবে (ইন্টারনেট লাগবে, প্রথমবার কিছুক্ষণ সময় নেবে)।
4. উপরে সবুজ **Run ▶** বাটনে চাপ দিন। একটি **Emulator** (নকল ফোন) না থাকলে Device Manager থেকে একটি বানান, অথবা ফোন USB দিয়ে লাগান।
5. অ্যাপ চালু হলে Splash → Login দেখবেন। যেকোনো বাটনে চাপলে পরের (placeholder) হোম স্ক্রিনে যাবে।

## এখন পর্যন্ত যা আছে
- Splash screen (টিল+সোনালি গ্রাডিয়েন্ট, লোগো, লোডিং)
- Login screen (Facebook / Google / Phone বাটন)
- ডিজাইন সিস্টেম (মূল অ্যাপের রং: টিল + সোনালি)

> নোট: এখন লগইন বাটনগুলো শুধু পরের স্ক্রিনে নিয়ে যায় (ডেমো)। আসল Facebook/Google লগইন Phase 2-তে সার্ভারের সাথে যুক্ত হবে।
